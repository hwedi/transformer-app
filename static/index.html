How it works

Gases in a transformer's oil change when something inside goes wrong. Two models read them.

  1. Add readings

    A CSV of 420 readings of four gases.

  2. We check the file

    Anything missing or odd stops here, with the reason.

  3. Two models read it

    One names the fault. One estimates the days left.

  4. You see how sure we are

    Unsure answers are flagged for a person.

What it cannot do

  • It learned from one public dataset, not from real transformers.
  • It is a decision aid. An engineer makes the call.
  • It is less precise when a long life remains.
  • The range is a guide, not a guarantee.
Words used here
Fault diagnosis
What is wrong right now: normal, partial discharge, low-energy discharge or low-temperature overheating.
Remaining life
How many days the transformer should keep working.
Confidence
How strongly the model favours its answer. Below the threshold, a person checks.
GRU
A neural network that reads data in order and remembers what came before.

Performance

Results on 900 transformers the models had never seen.
